# Bugbound Season 2

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users and Purpose
Developers relearning React and learning Next.js through deliberately broken source code. Learners read a concept and incident, reproduce behavior in a real Next.js route, edit source in their desktop editor, and run executable checks to unlock the next incident.

## Product Truth
- Thirteen ordered incidents in three acts. No simulated editor, fake telemetry, or automatically supplied solutions.
- Full Concept stays expanded beside the investigation on desktop. Hints remain deliberate, initially concealed disclosures.
- Earned completion, successfully saved completion, and latest verification are distinct.
- Mobile users can browse lessons; solving requires a local source editor, recompilation, and a desktop browser.
- Season 1 and Season 3 are reference-only sibling projects.

## Approved Brand Commitment
Investigation Desk: a substantial advance from Season 1's field notebook, recognizable through Bugbound naming, incident notation, warm readable typography, and restrained detail. Persistent incident navigation, central investigation, and a dedicated Concept reference column replace the old card-based shell. No colored side-border cards, decorative dot grids, terminal costume, or decorative dashboard metrics.

## Implementation Constraints
Next.js 16, React 19, Tailwind 4. User authorized installing and using coss UI components as the primary control foundation. Preserve all intentional bugs under src/app/lab and src/proxy.ts, test IDs, manifest checks, hints, and reliability behavior. Work on main as explicitly authorized. Do not commit or publish without authorization.
